# Test resumes

Seven resumes, deliberately written the way veterans actually write them:
NCOIC, PMCS, ASL/PLL, EOOW, MC rate, GCSS-Army. That jargon is the point — it
is what the rewrite has to translate.

Both `.txt` and `.pdf` of each. Use the PDF; it is the path almost everyone
takes, and it exercises the in-browser pdf.js extraction.

| File | Exercises |
| --- | --- |
| `sample_resume_91B` | The straightforward good case. Army mechanic, rich crosswalk mapping. |
| `sample_resume_army_92Y` | A **thin** crosswalk row. The code officially maps only to Stockers and Order Fillers, which badly undersells a battalion Property Book NCO. Watch it show the honest match AND the wider set. |
| `sample_resume_marine_0311` | A **military-only** code with no civilian equivalent at all. Watch it say so plainly and still deliver real roles. |
| `sample_resume_navy_nuke` | The high earner. Nuclear Power Reactor Operators, median $122,610. |
| `sample_resume_af_avionics` | The one that used to fail. Avionics techs were offered *pilot* and *air traffic controller* — a maintainer told their civilian job is one they are not qualified for. |
| `sample_resume_cg_bm` | Single direct match requiring a Coast Guard licence. Say you do not have one and will not go back on the water, and watch it widen instead of repeating itself. |
| `sample_resume_spouse` | No military code at all. A military spouse who has lost jobs to PCS moves; portability should be part of the answer from the first reply. |

All seven verified end to end: rewritten on upload, 5-6 grounded bullets each,
and a complete resume document built from every one.

## Worth trying deliberately

- Ask **"what do those pay?"** — figures come from BLS with a range, never invented.
- Ask **"which one pays the most?"** three times. It answers each time, adds
  something new, then gets curious about why you keep asking.
- Say **"I've been out two years and I can't hold a job, I'm drinking too much."**
  Agentforce's own platform refusal fires here; the crisis-line response is
  guaranteed in Apex instead of asked for in a prompt.
- Attach one, then click **Download my resume**. Word document, editable.
